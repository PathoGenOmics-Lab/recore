For Panaroo, Roary, PPanGGOLiN, PanTA and PIRATE

Missing from the matrix. Still in the genome.

Recore searches every empty cell of a pangenome matrix in the assemblies, puts back the genes that are really there, and keeps the evidence for each one.

Get started Open a real report ↗ GitHub

Reads your pangenome and the assemblies. Writes a corrected matrix and a report. Never edits your files.

1

Install

Two commands. Recore uses minimap2 to search.

minimap2
$ conda install -c bioconda minimap2
$ brew install minimap2
$ sudo apt install minimap2
Recore
$ cargo install --git https://github.com/PathoGenOmics-Lab/recore --locked

Needs Rust 1.85 or newer (rustup.rs), about a minute to build. Check with recore --version. The source is on GitHub.

        6
        
    One setting that matters
    
        
    --matrix-policy picks which evidence reaches the corrected matrix. All of it stays in the audit files.
    
      
    
      
    
        
        
        
      
    
      
    
        
    Ten genes Recore found where the matrix said absent. Pick a policy:
    
        
    Same locus, by annotation or by its neighbours
    
        
    Full-length gene, found by sequence
    
        
    Partial copy or pseudogene
    
        
    Neighbours disagree, or it is a paralog
    
        
    
      
    
    
    
  
    

  
    
    
    
      
    
        ?
        
    If something looks off
    
        
    The questions people ask first.
    
      
    
      
    
        
    
          It says minimap2 was not found
          
    Recore runs minimap2 for every search. Install it (step 1) and check that minimap2 --version works in the same terminal.
    
        
    
        
    
          It finds no genome files, or no GFF matches a genome
          
    Name each file after its column in the matrix: column L1_AS00101 reads genomes/L1_AS00101.fasta and annotations/L1_AS00101.gff. FASTA can end in .fasta, .fa or .fna, GFF in .gff or .gff3, gzipped or not.
    
        
    
        
    
          It rescued nothing
          
    Read the Gaps: line of the log. Genes in fewer than 10% of genomes are not searched; --min-prevalence 0 searches them all. Check the file names (above), and use --preset asm20 for divergent species.
    
        
    
        
    
          Will it change my matrix or my GFFs?
          
    No. It reads them and writes everything new into the output folder, recore_output/ unless you pass -o.
    
        
    
        
    
          How long does it take, and how much memory?
          
    800 genomes of 4.9 Mb take about 20 seconds on a laptop with 8 threads and about half a gigabyte of memory, which grows by about 0.5 MB per genome. The measurements.
    
        
    
        
    
          Can I try another policy without searching again?
          
    Yes. Add --search-cache cache/ to both runs: the second one aligns only what changed.
    
        
    
        
    
          How do I describe it in a paper?
          
    For the default policy: We used Recore with the balanced matrix policy, which rescues full-length false absences while retaining partial or disrupted homologues as multistate audit-only evidence.
